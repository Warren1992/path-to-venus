PATH TO VENUS — STORE PRODUCTS FIRST

This update moves the LIVE Fourthwall product grid to the top of the Store page and compacts mobile navigation.
The existing Fourthwall configuration, cart, size selection, prices, and checkout scripts are unchanged.

INSTALL:
1. Open https://github.com/Warren1992/path-to-venus in a browser and ensure the main branch is selected.
2. Open the root of the repository (not assets, merchant, or blog).
3. Select Add file > Upload files, and choose store.html from this ZIP.
4. Replace the existing store.html file and commit to main.
5. When GitHub Pages deployment is successful, visit https://pathtovenus.com/store.html?layout=products-first

If GitHub's upload interface will not replace the file, open store.html, click Edit (pencil), select all the HTML, paste this file's contents, then commit.
Do not delete merchant/fourthwall-config.js or assets/fourthwall-store.js.
